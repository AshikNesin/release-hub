Default package name

Prefills package names when adding a platform: prefix.slug — e.g. com.example + appname → com.example.appname.

Beta testers

Invited to the internal-testing track of every Play-published app — automatically on each internal release, or via invite testers on an app's page. The Play API can only invite Google Groups (create one free at groups.google.com and add your testers' emails there); the copied internal link then works for every group member.

Re-syncing replaces the track's tester list: whatever is saved here becomes the entire list. Testers you invite by email directly in Play Console are not visible to the hub — clear this field and re-invite, and the Console-added testers are removed. Prefer managing testers only here (or only in Console), never both.

Release retention

After each direct upload, older direct releases beyond this count are deleted (artifact file included) — keeps storage bounded. Blank or 0 keeps everything. Applies to every app unless overridden on the app's Configuration tab; Play channels are never pruned.
